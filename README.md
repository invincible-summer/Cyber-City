# 霓湾 / Neon Haven

一座温暖、安静、带有复古科技气息的近未来滨海城市——以独立街区组成、可持续扩建的 3D 场景库。
当前形态：**可自由观察和摄影的城市场景展示程序**（无玩法、无 NPC）。

## 当前内容（chapter1-2 后）

- **两个生产场景单元**（经菜单或门户切换，稳态严格单活动加载）：
  - **M01 余晖街区 `m01_afterglow`**：120×160 米核心街区，主街、侧巷、修理铺广场、街尾高架站口、生活广场、屋顶露台、远景塔楼；固定傍晚"雨停后的蓝调时刻"光照（LightmapGI 静态烘焙）。街面有成组叙事道具：花钵行道树、自行车棚、便利店外摆（冰柜/报刊架/A 字立牌）、罩布收摊的夜宵摊车、维修铺广场 A 板/斜靠自行车/油桶托盘、生活广场晾衣绳等。
  - **M01 余晖维修·店内 `m01_repair_interior`**（chapter1-2）：可推门进入的两层室内——一层修理工坊（柜台/工作台/工具墙/待修摩托/售货机）+ 通高中庭 + 直跑楼梯 + 二层居家阁楼（沙发/黄昏窗景餐桌/床龛/终端角），**第一人称步行观察**（重力贴合、踏步上楼、身体半径阻挡，无物理引擎）。
- 两种相机模式：街区**自由飞行**（Q/E 升降）/ 店内**步行**（WASD，Shift 跑）；固定机位切换（街区 7 / 店内 4）。
- **门户**：走到维修铺门口，门自动开启并提示"进入 余晖维修·店内"，按 **F** 载入店内；店内门口按 **F** 返回街道。
- 经济 / 均衡两档画质；失焦与最小化自动节流。
- 截图（F12，保存到 `user://captures/` 并带 JSON 元数据与渲染计数）、诊断面板（F2）、隐藏全部 UI（F1）。
- 严格单活动地图的加载/卸载架构（生命周期与合同测试见 `docs/chapter1_2/review.md`）。

## 环境要求

- Windows x86_64。
- Godot **4.7.2 stable**（本工程按此版本开发与验证）。无需 Python、Blender 或网络。

## 启动

```powershell
& "D:\Godot\Godot_v4.7.2-stable_win64.exe\Godot_v4.7.2-stable_win64.exe" --path <项目目录>
```

默认进入余晖街区，经济档（0.80 渲染比例 / 30 FPS 上限）。

## 操作

| 输入 | 行为 |
| --- | --- |
| 鼠标右键按住 | 转向观察；松开恢复指针 |
| W/A/S/D | 移动（飞行图另支持 Q/E 下降/上升；步行图 Q/E 无效） |
| Shift | 加速（飞行 3→9 m/s；步行 2.2→4.4 m/s，踏步上楼 0.3 m） |
| 滚轮 | 调整移动速度 |
| 数字键 | 切换固定机位（街区 7 个 / 店内 4 个） |
| Home | 回默认机位 |
| **F** | 门户：门口进入店内 / 店内返回街道（靠近门时门自动开合） |
| F1 | 隐藏/恢复工具 UI |
| F2 | 诊断面板（FPS/绘制/节点/内存，4Hz） |
| F12 | 截图（自动隐藏 UI，PNG+JSON 存 `user://captures/`） |
| Esc | 释放指针 / 打开地图与工具菜单 |

## 画质档位

| 项目 | 经济 Eco（默认） | 均衡 Balanced |
| --- | --- | --- |
| 3D 渲染比例 | 0.80 | 1.00 |
| 帧率上限 | 30 | 60 |
| 抗锯齿 | FXAA | MSAA 2× |
| Glow | 关 | 低强度 |
| 粒子/探针/补光 | 关 | 开（≤2 探针、≤2 局部粒子） |
| 失焦 / 最小化 | 10 FPS / 5 FPS+暂停动画 | 同左 |

设置保存在 `user://settings.cfg`；非法值回落 Eco。两档共用同一套烘焙光照。

## 已知限制

- 招牌与 A 牌中文字形由项目内 **Noto Sans SC（OFL 1.1，随仓库分发）** 在制作阶段栅格化生成纹理；许可与哈希见 `docs/asset_sources.md`。
- 性能数据以 `user://benchmarks/<run_id>/summary.json` 与 `summary.csv`（结构化证据）为准；工作集等系统级指标由 `tools/sample_process.ps1` 外部采样补充。
- 无人值守会话运行 `--perf` 时窗口拿不到前台焦点会触发失焦中止（测量有效性设计）；本机用 `tools/focus_keep.ps1` 保持前台后采样有效。
- chapter1-2 遗留：实机 F 键门户往返步行体感与摄影模式巡走清单为人工项（数据/合同层已自动验证，见 `docs/chapter1_2/review.md`）。
- `build/windows/neon_haven.exe` 为 chapter1-1 内容的导出产物；chapter1-3 最终全管线重导出与独立目录实测列入 `docs/backlog.md`（WP10/G6）。
- chapter1-3 工程信任链已落地（BuildContract/manifest v2/烘焙状态机/verify 只读/画质与 occlusion 唯一权威/benchmark 测量快照，见 `docs/chapter1_3/review.md`）；§19–§27 主场景美术深化（WP8/WP9）尚未开始。
