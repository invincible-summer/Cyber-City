## 1. 本轮发现并修复的核心缺陷

### 1.1 场景"里外翻转"（根因级，影响全部画面）

`GenLib.MeshBuilder` 的四角约定是"从法线一侧看逆时针"，而 Godot 正面为**屏幕顺时针**绕序，
导致所有生成面片的正面落在声明法线的**反侧**：

- 单面招牌（店面/维修铺）从临街面被剔除 → 全部不可见；
- 双面立柱站牌可见的一侧是另一面板的背面 → 文字镜像；
- 地面/路面顶面被剔除 → 街面呈无细节平面；
- 窗框"悬浮"（墙面渲染的是楼体远端内壁）。

**修复**：`gen_lib.gd _flush()` 输出三角形反转（q0,q2,q1 / q0,q3,q2）。
实测验证：临时渲染脚本确认"东侧起步+图左下 UV"从法线侧读字正确；反转后全部招牌可见且方向正确。
已通过截图复核：`余晖维修`、`海风便利`、`湾流洗衣`、`霓湾站` 全部可读、方向正确。

### 1.2 编辑器烘焙 X2 复制循环（工程，WP1 遗留）

现象：每次编辑器烘焙后 LightmapGIData 出现成对 `X/X2` user 路径，map.tscn 残留
`BakedWorld2/AuthoredGeometry2/...` 空覆盖节点，烘焙数据膨胀（13 users vs 实际 6 网格）。

根因（两点，均已修复）：

1. `assemble_m01.gd` 曾把 owner 设到**实例子场景内部节点**上，pack 时写入"实例覆盖子节点"，
   编辑器加载时与子场景自身节点叠加复制。
2. Godot 4.7 的 LightmapGI 烘焙对"LightmapGI 子树内的 PackedScene 实例"会复制出 X2 副本
   并随保存写回（首版单体 map.tscn 无此问题）。

**修复**：assemble 改为**展平嵌入**——实例化后把子场景节点上移到同路径的普通容器
（`Generated/`、`Authored/` 节点名保留，节点路径与 region_manifest 一致），map.tscn 不再含
`instance=` 引用；同时 owner 只设在实例根/普通节点，不进实例内部。修复后：
precheck 11 网格/7 UV2，烘焙 users=7（6 网格 + Backdrop），expected 无 missing。
